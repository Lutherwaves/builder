# jotter

A tiny command-line notebook. Notes are Markdown files under one folder. Python 3 standard library only.

    python3 jotter.py list                # lists your notes
    python3 -m unittest -v                # runs the tests

Settings live in `config.json` next to your notes (see `config.example.json`).
The log goes to `jotter.log`. If something breaks, attach `jotter.log` to your bug report.
